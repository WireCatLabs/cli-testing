# Generation

- [yandex-disk](yandex-disk/README.md): `ydisk` on cli-template 0.25.0, cli-core 0.689.0 and cli-base 0.110.0 — hand-written
  lines and hours from `new` to green, against notion-cli.
- [source-manifest](source-manifest/README.md): `attio` built only from `wirecat.config.ts` and one hook, on
  cli-template 0.28.0 — hand-written lines and time, against hubspot-cli and bitrix24-cli.
- [linear-from-config](linear-from-config/README.md): `linear`, an issue tracker over GraphQL, from one
  `wirecat.config.ts` with no hooks — hand-written lines, time to green and the gaps, against attio-cli.
