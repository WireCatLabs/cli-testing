Статья «Python» входит в общий для всех языковых разделов Википедии расширенный список необходимых статей.
Её развитие вплоть до статуса избранной является важным направлением работы русского раздела Википедии.
Вы можете посетить страницу проекта «Мириада», который занимается улучшением наиболее важных статей Википедии, и, при желании, присоединиться к нему.
Эта статья содержит текст, переведённый из статьи Python (programming language) из раздела Википедии на английском языке.
Список авторов находится на странице истории правок оригинальной статьи. Информация о включении текстов из других источников и их авторах может быть размещена на странице обсуждения оригинальной статьи.
