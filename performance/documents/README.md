# Document reading

Measurements of document conversion, shared retrieval and source-backed memories.

- [annotation-transfer](annotation-transfer/README.md): packaged old/new SDK copy, reference and identity collisions, interruption/replay and retention of source annotations.

- [drive-sheets](drive-sheets/README.md): guarded executable acceptance for native spreadsheet ranges, cell writes and generated Sheets methods.

- [drive-release-polish](drive-release-polish/README.md): isolated executable setup, validation, profiles and legacy settings checks before public-release polish.

- [drive-shared-store](drive-shared-store/README.md): offline import, provenance, tags and message links across Drive, Telegram, MAX and Memo executables.

- [drive-ai-quality](drive-ai-quality/README.md): real-model extraction over synthetic decisions, drafts, uncertainty, assignments, injection and Spanish negation.

- [drive-decisions](drive-decisions/README.md): installed-package decision replacement, confirmation,
  reversal, event time and local account/policy boundaries.

- [drive-ai](drive-ai/README.md): executable extraction checks with a loopback model responder,
  source evidence, explicit saves, error handling and an in-flight source change.

- [drive-complex](drive-complex/README.md): seven read-only multi-tab Google Docs plus compiled
  SDK-fixture checks for nested content, edit/move/trash recovery, scope exit/re-entry and context retention.

- [drive-push](drive-push/README.md): live check (2026-10-21) that Markdown, DOCX, CSV and XLSX convert into
  existing native Docs and Sheets, and which Drive field detects a real edit (revision id, not `version`); later
  sections: formatting, ticks, `mirrors sync` acceptance and two-way sync (2026-10-22), Google Docs' own Markdown
  editing and the change feed (2026-10-23), `mirrors watch` (2026-10-24).

- [html-readers](html-readers/README.md): regex reader, defuddle and Readability with Turndown compared on 30
  public HTML pages (2026-10-13).

- [native-markdown](native-markdown/README.md): what programs can do with a `.md` file Google Docs opens natively
  (read yes, piece-by-piece edits no, whole-file replace yes), and when drive's mirrors are still needed (2026-10-25).

- [offline-catalog](offline-catalog/README.md): synthetic Drive hierarchy, metadata queries, folder context, account isolation and released JSON/MCP contracts, including [0.11.1 list-query acceptance](offline-catalog/README.md#released-0111-list-queries); includes a [standards gap review](offline-catalog/standards.md) and an [isolated Google checker and unrun live checklist](offline-catalog/live-checklist.md).

- [Links introduced by message edits](edited-message-links/README.md): compiled sync, old SDK writers and upgrade repair.

- [drive-command-contracts](drive-command-contracts/README.md): synthetic compiled-CLI download guards,
  status privacy and MCP command/argument checks before the 2026-10-24 candidate release.
