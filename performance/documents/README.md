# Document reading

Measurements of how documents become text before they are indexed and searched.

- [html-readers](html-readers/README.md): regex reader, defuddle and Readability with Turndown compared on 30
  public HTML pages (2026-10-13).

- [offline-catalog](offline-catalog/README.md): synthetic Drive hierarchy, metadata queries, folder context, account isolation and released JSON/MCP contracts; includes a [standards gap review](offline-catalog/standards.md) and an [isolated Google checker and unrun live checklist](offline-catalog/live-checklist.md).
